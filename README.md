# 🧩 Login App (Jetpack Compose + DataStore)

A simple and modern **Android Login App** built using **Kotlin** and **Jetpack Compose**.  
This project demonstrates how to handle **user registration and login** using **DataStore**, **Coroutines**, and **Jetpack Navigation** — all in a clean, declarative UI.

---

## 🚀 Features

✅ Register new user (Email & Password)  
✅ Save user data securely using **DataStore**  
✅ Login and validate credentials  
✅ Navigate between screens (Register → Login → Details)  
✅ Built with **Jetpack Compose** for modern UI  
✅ Uses **Kotlin Coroutines** for asynchronous data operations  

---

## 🧠 Tech Stack & Skills Used

- **Kotlin**
- **Jetpack Compose**
- **DataStore Preferences**
- **Coroutines**
- **Navigation Component (Compose Navigation)**
- **Material3 Design Components**
- **MVVM (basic structure)**
